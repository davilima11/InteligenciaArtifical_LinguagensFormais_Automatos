# Inteligência Artificial, Linguagens Formais e Autômatos

Repositório com materiais e atividades práticas da disciplina **Inteligência Artificial, Linguagens Formais e Autômatos**.

O objetivo deste repositório é organizar conteúdos, exemplos e exercícios relacionados aos fundamentos de linguagens formais, gramáticas, cadeias, alfabetos, derivações e autômatos.
